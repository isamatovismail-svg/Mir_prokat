# 🏰 Mir Prokat — Веб-система и Telegram-бот проката оборудования для мероприятий

Современная система бронирования и управления прокатом оборудования, мебели, текстиля, посуды и декора для мероприятий (свадьбы, банкеты, корпоративы, юбилеи).

---

## 🌟 Ключевые возможности

### 1. Клиентский веб-сайт
- **Главная страница в стиле Modern Rental:** элегантный светлый дизайн, оптимизированный под мобильные телефоны.
- **Интерактивный 6-шаговый калькулятор мероприятия:**
  1. Количество гостей (быстрые кнопки: 10, 20, 30, 50, 70, 100, 150, 200, 300+ или произвольное число).
  2. Тип мероприятия (Свадьба, День рождения, Юбилей, Корпоратив, Банкет, Выпускной, Детский праздник, Фуршет).
  3. Выбор пакета (BASIC, STANDARD, PREMIUM) с динамическим расчётом комплектации.
  4. Дополнительные товары (+ стулья, столы, бокалы, арка, цветочные композиции).
  5. Проверка даты с контролем складских остатков в реальном времени.
  6. Форма бронирования (имя, телефон, telegram, адрес, доставка, монтаж, комментарий).
- **Каталог оборудования:** поиск товаров («стул», «тарелка», «скатерть»), фильтрация по категориям и сортировка по цене.
- **Публичная страница заказа (`/orders/ORD-XXXX/`):** статус-бар выполнения заказа, состав, финансовый баланс (оплачено, остаток, залог).
- **Информационные страницы:** «Как это работает» (4 шага), «Контакты и склад», «Готовые комплекты».

### 2. Защита от двойного бронирования и складской учёт
- Серверная валидация: система никогда не доверяет данным с клиента.
- Учёт доступных физических остатков за вычетом единиц в ремонте и уже зарезервированных товаров на выбранную дату.
- Автоматическое создание складских резервов (`StockReservation`) при переводе заказа в статус `CONFIRMED`.

### 3. Защищённая панель управления (Админка)
- **Дашборд:** сводка за сегодня (новые заявки, активные заказы, мероприятия сегодня, % загрузки склада, предупреждения о товарах ниже минимального остатка).
- **Заказы:** фильтрация по всем 11 статусам (`NEW`, `PENDING`, `CONFIRMED`, `PAYMENT_PENDING`, `PAID`, `PREPARING`, `READY`, `DELIVERING`, `EVENT`, `COMPLETED`, `CANCELLED`), поиск, изменение статуса с автоуведомлением клиента, управление оплатой (внесение аванса, расчет остатка).
- **Интерактивный календарь:** визуализация загрузки оборудования по дням на базе FullCalendar.
- **Склад:** учёт общего количества, единиц в ремонте, зарезервированных сегодня, свободных остатков и минимального запаса.
- **Каталог товаров и пакеты:** управление правилами расчёта пропорций (например, 1 стул на гостя, 1 стол на 10 гостей, 1 комплект приборов на гостя).
- **Клиентская база:** карточка клиента, общая сумма заказов (LTV), история, VIP-статус, заметки менеджера.
- **Аналитика:** выручка, средний чек, топ самых арендуемых товаров, популярность пакетов.

### 4. Telegram-бот (@mir_prokat_bot)
- **Главное меню:** «Рассчитать заказ», «Каталог», «Мои заявки», «Проверить дату», «Связаться с менеджером».
- **Пошаговый сценарий подбора и бронирования:** сбор данных о гостях, типе события, пакете, дате и контактах.
- **Интерактивные уведомления администратору:** детальное сообщение с составом заказа и кнопками: «✅ Принять», «❌ Отклонить», «📦 Проверить склад», «✏️ В админку».

## 🚀 Быстрый запуск

### 1. Активация виртуального окружения
```bash
cd /home/linux/PycharmProjects/Mir_prokat
source .venv/bin/activate
```

### 2. Применение миграций и загрузка демо-данных
```bash
python manage.py migrate
python manage.py seed_data
```
> Демо-база будет автоматически наполнена категориями, товарами, пакетами (BASIC, STANDARD, PREMIUM), типами событий, услугами доставки и тестовыми заказами.

### 3. Доступ в панель администратора
- **URL:** [http://127.0.0.1:8000/admin-panel/login/](http://127.0.0.1:8000/admin-panel/login/)
- **Логин:** `admin`
- **Пароль:** `admin123`

### 4. Запуск веб-сервера
```bash
python manage.py runserver 0.0.0.0:8000
```
- Главная страница: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- Калькулятор: [http://127.0.0.1:8000/calculator/](http://127.0.0.1:8000/calculator/)
- Каталог: [http://127.0.0.1:8000/catalog/](http://127.0.0.1:8000/catalog/)
- Пример заказа: [http://127.0.0.1:8000/orders/ORD-1042/](http://127.0.0.1:8000/orders/ORD-1042/)

### 5. Запуск Telegram-бота (опционально)
1. Создайте бота через `@BotFather` и укажите полученный токен в файле `.env`:
   ```env
   TELEGRAM_BOT_TOKEN=123456789:ABCdef...
   TELEGRAM_ADMIN_CHAT_ID=12345678
   SITE_URL=http://127.0.0.1:8000
   ```
2. Запустите бота:
   ```bash
   python manage.py run_bot
   ```
